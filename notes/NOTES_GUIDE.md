# 📝 Direktori Catatan & Standar Prompt Pengembang (FPManager)

Direktori ini digunakan khusus untuk menyimpan berkas catatan kerja, instruksi prompt baku, dan perencanaan fitur pengembang.

---

## 📄 Berkas Catatan

1. `aturan_prompt.txt`:
   - Berkas instruksi standar kepatuhan prompt pengembangan:
     - Judul menggunakan font Jakarta (*Plus Jakarta Sans*).
     - Menghindari emotikon mentah Windows/OS, menggunakan ikon Font Awesome.
     - Tidak mengubah fungsi utama aplikasi.
     - Konsistensi margin dan padding tabel (mengacu ke tabel projek).
     - Tidak menambah fungsi baru tanpa instruksi.
     - Tidak merubah CSS secara drastis tanpa persetujuan.
     - Mengutamakan performa paling ringan dan efisien.
     - Menjaga UX dan kemudahan penggunaan.
     - Konsistensi warna tema (Zinc, Indigo, Emerald, Rose, Amber, Purple).

2. `next_fitur.txt`:
   - Daftar backlog ide, masukan, dan rencana fitur yang akan dikerjakan pada iterasi berikutnya.
